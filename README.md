# Linux Persistence Fieldbook

A fieldbook for investigating Linux persistence mechanisms, their evidence, and detection limits.

The [publication order](publication_order.csv) lists 74 planned investigations; a planned item is not a completed or validated investigation. The [fieldbook archive](linux-persistence-fieldbook-publishing-order-v2.zip) contains the existing catalog, notes, examples, scripts, and tests. The repository tree is not yet unpacked.

Related project: [HookScope](https://github.com/moalinazli/HookScope), an offline auditor for Python startup hooks.
